# Больница Карачун 3D — Godot

Порт игры «Больница Карачун 3D» 45.1.0 (HTML/three.js) на **Godot 4.7.2** (рендер Mobile).

## Что внутри
- **Симуляция** (`scripts/sim/`): цепочка патчей 45.x перенесена один-в-один как цепочка наследования GDScript
  (`s00_core → s01_motion → s02_mech → s11 → s12 → s17 → s18 → s24 → s25 → s41 → s42 → s45body → sim.gd`):
  экономика, месяцы по 30 дней, 12 уровней и их цели, болезни, диагностика, лечение, персонал, курсы, кредиты, участки, ЧП, инспекции.
- **Слой тел** (`s45body.gd`): скорость/разгон/торможение, разворот на месте, вежливое ожидание, точные остановки.
- **Вид** (`scripts/view/`): изометрическая камера, комнаты и мебель 45.x (экспорт `furn_i46.js` → `furn46/*.scn` с LOD),
  слияние статики по материалам, персонажи Quaternius с позами лечения (лёжа в сканере/на кровати, выдача таблеток, шланг насоса и т.д.).
- **Интерфейс** (`scripts/ui/`): HUD и меню на русском, скорости ×1/×2/×4 (анимации идут в игровом времени).
- **Сохранения**: `user://hohotun_trial45_save_v1_L<n>.json`; импорт сохранения 45.x через буфер обмена (меню → «Импорт»).

## Запуск
Откройте папку в Godot 4.7.2 и запустите `scenes/main.tscn`.

Проверка без графики (все уровни, автоигрок):
```
godot --headless --path . -s res://harness/run_levels.gd -- --lv=0 --days=700 --saveday=60
```

## Сборка
Пресеты экспорта: `Android` (пакет `com.hohotun.karachun.godot`) и `Windows`.
Ключ подписи в репозиторий **не входит**; путь/логин/пароль передаются переменными окружения
`GODOT_ANDROID_KEYSTORE_RELEASE_PATH/_USER/_PASSWORD`.
